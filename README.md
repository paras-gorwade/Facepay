# FacePay

AI-powered contactless campus payment system using face recognition.

## Overview

FacePay is an AI-powered campus payment system designed to enable
contactless payments using facial recognition.

The system identifies registered students through their face and
provides the foundation for a secure and convenient campus payment
experience.
